## The numbers behind "110 viewers"
Free webinars usually get **30–40%** of registrants to show up live.
→ To get **110 live**, you need about **320 registrations**.
→ Target set in the plan: **350 registrations** (safety margin).

If ~5–8% of live viewers buy → **6–9 sales × 4,900 ₪ ≈ 29,000–44,000 ₪**.
Follow-up messages after the webinar usually add more.
